# 对原制作 Prompt 的完整覆盖审计

审计日期：2026-11-03。依据为上一级 `AI评论员_交给6.1-sol的制作Prompt.md`、当前代码、自动化结果、运行中服务与用户截图。新要求“概率 80%”覆盖原默认 45%。后续用户已明确授权上传，本次按功能分支提交推送，不合并 main 或发布。

**结论：没有全面完成原任务书的最终验收。** 后端和页面功能闭环已经实现，但“真正会接话、自然可爱”的核心效果此前没有被真实模型验证。原 42 项主要测试权限、任务、数据一致性和页面 JS，不能证明语气合格。用户截图暴露了真实缺口，不能以“这是 Mock”作为产品效果已经达标的理由。

状态定义：**通过**＝本地代码及针对性自动化已验证；**部分**＝有实现但不能证明全部语义/视觉效果；**待验收**＝需要真实模型、人工评分或实际工具/真机；**允许延期**＝原任务书允许首版不做，已明确边界。下表中的“通过”只覆盖注明的本地范围。

## 本轮发现与修复

| 缺口 | 根因 | 本轮处理 |
| --- | --- | --- |
| 不同原文接同一句日记口号 | Mock 把原帖前 26 字拼到同一个结尾 | 删除通用兜底；未知输入 skip。示例只服务有限功能夹具，不冒充人格模型 |
| 截断词句导致不明所以 | 固定 `.slice()` 后加引号；记忆也可能切半句 | Mock 不长段照抄；输出检查截断引文；长记忆只保留完整短句/分句，无法提取则不用 |
| 重复检查漏过截图问题 | 整段相似度被不同引文稀释 | 加去引文后的连续公共片段检查，捕捉相同长结尾/骨架；禁止旧版通用口号 |
| 重试仍可能复读 | 第二次没有知道上次为何被拒 | 在同一总尝试上限内加入可信 repairHint，记录实际 `personality-2` 版本 |
| 无关旧话题被强行承接 | “第一次”“开心”等宽标签被当成相关 | 加具体物种叙述冲突检查与细节匹配，单靠初次/心情标签不命中 |
| 真人回复可能不在上下文 | 只取最近 8 条，目标较旧时被挤走 | 强制保留目标真人评论和其 AI 父评论，仍限制总数 8；检索与风格优先使用真人新回复 |
| 普通分享被插入科普 | 有事实就允许随机采 science | 仅在求知识/安全等适合语境中开放科普；伤亡优先认真承接 |
| 科普只能逐字照抄 | 输出被限定为等于一个事实原句 | 增加人工核对的自然短表达白名单；依旧禁止追加未核对知识。自由科学释义仍未全面实现 |
| 配置状态不清楚 | “Mock 演示”标签不足以说明未连接人格模型 | 发现页明确未连接真实模型；API 返回无凭据内容的配置状态；新增 doctor 自检 |
| 任意兼容供应商可能失败 | 只使用 OpenAI 的 token 参数 | 核对并分开 OpenAI/DeepSeek 参数；DeepSeek 短评论关闭 thinking，处理空白、截断、拒答 |
| 语气评测可能忽略复读 | 批量脚本没有把真实输出加入近期历史 | 后续案例保留已接受的实际评论；扩充 36 类输入与截图回归；人工评分脚本拒绝 Mock/空评分/重大问题 |
| 旧套话继续展示 | 改代码不会修改已落库结果 | 迁移 3 将已知旧 v1 Mock 口号标为 `quality_withdrawn`；不删原帖、真人评论或其他 AI 评论，不重新抽签 |

这些修复有回归证据，不代表真实语气已经通过。首次审计时没有模型 Key/模型 ID；后续用户已配置并充值，现已生成真实样本。人工评分仍未完成，不能宣称平均 4 分。

当前自动化 **63 项通过、0 失败、0 跳过**，静态检查通过。实际重启后保留 4 条原动态，撤回 2 条已知缺陷旧 Mock 套话；这是切换真实模型之前的记录；当前已切换真实 DeepSeek。用户自己的原动态、观察和真人评论没有因修复被清空。

## §8 人格提示词与输出校验

人格独立保存为 `server/prompts/community-bot.md`，当前 `personality-3`。只有 RealProvider 会将其作为 system 消息发送；帖子、评论、记忆在结构化 user 数据中。Mock 不声称使用系统人格。

JSON 字段、枚举、source 白名单、纯文本渲染、长度、常见隐私/危险/冒充/鉴定断言、重复骨架、截断照抄与事实表达均有规则检查及测试。schema 合法不等于事实与语气必然正确，完整自然语言真实性、安全性和自然感仍需真实模型输出与人工评审，不能标为完全通过。
