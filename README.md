# 共栖智护 · 生物多样性微信小程序

共栖智护面向校园及周边的自然观察与交流，通过观察记录、物种图鉴和社区互动，帮助用户发现身边的野生动物、分享自然故事，增进对生物多样性的了解。

## 已实现功能

- **自然地图**：根据个人观察记录展示地图点位，查看对应的观察信息。
- **观察记录**：支持选图、模拟识别、人工确认与纠错，保存观察时间和地点，并查看、删除记录。
- **物种图鉴**：浏览物种资料与详情，根据个人观察解锁图鉴。
- **自然广场**：发布文字动态、主动分享观察，支持点赞、评论和“我也见过”等互动。
- **AI 评论员“小黄”**：围绕动态内容随机参与评论，结合相关公开话题接话，支持对 AI 评论的有限回复，并显示明确的 AI 身份标识。
- **个人中心**：查看观察次数、已发现物种、贡献等级和近期观察记录。
- **互动与隐私设置**：管理动态可见性、共享话题记忆许可和 AI 互动开关，支持隐藏 AI 评论与提交反馈。
