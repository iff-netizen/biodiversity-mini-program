# AI 助手and评论员「小黄」

「小黄」是生物多样性微信小程序中的 AI 评论员，会围绕用户分享的校园自然见闻参与交流，用简短、自然、易懂的回复陪伴大家发现身边的自然。
「小黄」也是ai助手，在主页点击可移动小球，打开ai对话页面，可闲聊，回复小程序功能相关问题，自然科普等

## 已实现功能

- **根据动态内容评论**：结合当前动态生成回复，围绕用户实际分享的内容接话。
- **关联相关话题**：在用户允许的范围内，参考相关公开动态，让交流有上下文。
- **评论后继续互动**：用户回复小黄后，小黄有机会再接话一次。
- **随机参与交流**：按概率发表评论，并限制互动频率，避免过度打扰。
- **明确 AI 身份**：使用黄色头像和 AI 标识，便于区分 AI 评论与用户评论。
- **自主控制互动**：支持关闭 AI 互动、管理共享话题记忆许可，以及隐藏 AI 评论和提交反馈。
